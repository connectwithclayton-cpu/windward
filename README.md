# Windward

A human-in-the-loop supervision console for AI-dispatched field service.

An AI assigns technicians to jobs. You watch the board, see what it chose and what
it passed over, and override it when it is about to get something wrong.

Built around a question worth asking: when a system dispatches on its own, what is
the human actually for?

**Status:** in design. Nothing built yet.
